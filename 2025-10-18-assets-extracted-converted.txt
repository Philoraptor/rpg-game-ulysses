        90 +  ### Color Channel Mapping
        91 +  
        92 +  The conversion handles ABGR→RGBA color channel mapping:
        93 +  - **bmp-js output**: ABGR format (byte 0=Alpha, 1=Blue, 
           + 2=Green, 3=Red)
        94 +  - **PNG requirement**: RGBA format (byte 0=Red, 1=Green, 
           + 2=Blue, 3=Alpha)
        95 +  - **Alpha handling**: BMPs are 24-bit RGB (no alpha), so we
           +  force alpha=255 (opaque)
        96 +  
        97 +  ```javascript
        98 +  // ABGR → RGBA conversion
        99 +  pixelData[0] = bmpData.data[3];  // Red (from position 3)
       100 +  pixelData[1] = bmpData.data[2];  // Green (from position 2)
       101 +  pixelData[2] = bmpData.data[1];  // Blue (from position 1)
       102 +  pixelData[3] = 255;              // Alpha (force opaque)
       103 +  ```
